# 企查查桌面助手

云端平台只保存名单、任务和结果；桌面助手运行在一台同事的 Mac 上，主动从云端领取工单，并使用该 Mac 上已经登录的 Chrome/Safari 查询。电脑不需要开放公网端口。

## 云端配置

在云端服务设置一个随机密钥，和桌面助手保持一致：

```text
ZQC_WORKER_TOKEN=<至少 32 位随机字符串>
```

重新部署云端服务后，企查查页面的“运行位置”选择“我的电脑（桌面助手执行）”。点击“开始批量查询”后，任务会显示为“等待桌面助手”。

## Mac 配置

在项目目录执行一次：

```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
export ZQC_WORKER_TOKEN='<与云端相同的密钥>'
export ZQC_WORKER_SERVER='http://zhengqi-ai-workflow-platform.winsun.net.cn'
export ZQC_AUTH_USER='<云端平台账号>'
export ZQC_AUTH_PASS='<云端平台密码>'
./桌面查询助手.command
```

助手启动后会持续等待任务。Chrome 调试模式或 Safari 登录方式和本机模式相同；首次查询前在本机浏览器登录企查查。出现验证码、登录或风控验证时，助手会把任务标为“等待登录或验证”，在本机处理后回到云端点击“继续未完成项”。

## 安全和运行要求

- 不要把 Chrome 的 9222 端口暴露到公网；助手主动访问云端即可。
- 一台电脑同时只运行一个助手进程，一个企查查账号的任务串行执行。
- 电脑需要保持开机、联网和浏览器登录状态。
- 云端必须设置 `ZQC_WORKER_TOKEN`，否则不要把桌面助手接口暴露在公网。
- 如果云端启用了 `ZQC_AUTH_USER` / `ZQC_AUTH_PASS`，桌面助手也必须设置这两个环境变量。
