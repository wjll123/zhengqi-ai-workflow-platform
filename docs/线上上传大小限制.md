# 线上上传大小限制

企查查等任务通过 `POST /api/upload` 上传文件。2026 年 10 月 27 日核查时，
`zhengqi-ai-workflow-platform.winsun.net.cn` 的 nginx 对约 2 MB 的请求直接返回
HTML 格式的 `413 Request Entity Too Large`，请求未到达 Flask。项目中约 4.3 MB
的工作簿因此无法上传。

在该域名对应的 nginx `server` 配置中设置：

```nginx
client_max_body_size 50m;
```

将配置部署到负责反向代理的 nginx（若在容器内运行，就改容器使用的配置），先执行
`nginx -t`，通过后重载 nginx。Flask 同样限制请求体为 50 MiB，并对超过限制的请求
返回 JSON 说明。nginx 的 `50m` 与 Flask 的 50 MiB 一致。

发布时同步部署本仓库的最新代码；旧前端无法显示具体错误。发布后用无业务数据的
2 MB 测试文件验证上传成功，再用超过 50 MiB 的文件验证页面显示大小限制提示。
测试文件应在验证后删除。
