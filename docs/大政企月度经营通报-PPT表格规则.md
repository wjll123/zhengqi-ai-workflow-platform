# 大政企月度经营通报：PPT 表格输出规则（2609 样本）

## 范围与结论

样本输出为 `大政企月度经营通报【2026年8月】（渠道）.pptx`，共 14 页。第 3–14 页各有一张原生 PPT 表格。交付包的《大政企月度经营通报更新说明》明确：**本批只更新 P11–14**。本规则优先定义这四页；P3–10 虽有表格，但本批数据源不足以自动重算。

P11–14 的直接源文件是 `客经中心-大政企客经场景运营周报+(260831）+-地市.xlsx`。另一个 `商企分享升级又续约数据.xlsx` 对应平台现有「商企续约数据处理」中间任务；P13 表格本身直接取下述周报工作簿中的“月报用”工作表，不需从该 SQL 结果重复拼接。

## 数字和样式

- 数量列复制源数值，以整数显示；源中的文本 `-` 保持为 `-`，不能强制转成零。
- 百分比列读取源单元格的实际数值，乘 100 后按十进制四舍五入到 **1 位小数**，追加 `%`。例如 `0.1785` 显示为 `17.9%`。不要先用二进制浮点结果再四舍五入，否则边界值会错。
- 百分比目标列：P11 为第 6、10、14、18 列；P12 为第 6、8、12、14、18、20 列；P13 和 P14 均为第 5、7、9、11 列。
- 每个百分比列单独对 **21 地市**排名，排除全省与源值为 `-` 的地市。前三名标蓝 `#4472C4`，后三名标红 `#C00000`；其余沿用模板样式。2609 样本逐列验证符合该规则。若将来出现并列，需确认并列取舍规则，不能仅凭本批样本推断。
- 沿用原 PPT 的标题、表头、字体、合并单元格、备注、页脚和布局，仅替换已核对的数据格。文本点评可能包含月份和排名，不能在没有明确生成规则时自动保留为新账期事实。

## 可验证性

把 P11–14 的目标数据区与源表按上述映射逐格比较，排除展示用的片区列后共 **1,232 格一致，0 格差异**：P11 374 格、P12 418 格、P13 220 格、P14 220 格。百分比使用十进制四舍五入；若按常见浮点算法会误报 3 处边界差异。红蓝字体也逐列通过前三/后三名验证。

## 平台操作路径

任务中心 →「大政企月度经营通报表格更新（P11–14）」→「选择数据源」。在任务页分别选择已有的周报 `xlsx` 和同账期 PPT 模板；若文件尚未进入平台，可点「增加新文件」上传，再从列表选择。执行前校验源工作簿账期、四张工作表、PPT 封面月份、表格结构和地市顺序。输出写入平台成品目录，不覆盖上传文件。

当前平台已内置 2609 样本作为可选源和模板。P3–10 仍为待源范围。若目标是生成整份新账期 PPT，还需为点评文字、非数据页及并列排名建立逐项规则和验收样本。
